# pi-architect

Architect a feature with [Pi](https://github.com/earendil-works/pi) before you build it.

The agent walks through five visual phases: Frame, Explore, Decide, Design and Slice.
You approve each phase before it moves on. The result is a plan file that another agent can build from.

> Work in progress. See [DESIGN.md](./DESIGN.md) for the plan.

## Install

```bash
pi install npm:@jordyvanvorselen/pi-architect
```

## Develop

```bash
npm install
npm run lint
npm run typecheck
npm test
```
